# Collagent Docs

Collagent lets several people (and, when you want, several agents) work in
the **same live coding-agent session**. One person hosts the agent — Claude
Code, Codex, Cursor, Gemini CLI, Goose, or OpenCode — everyone else joins a
room and works with it in real time.

## Two commands to try it

```
collagent create
```

```
collagent join A7K2
```

That's the product. Everything else in these docs is detail.
